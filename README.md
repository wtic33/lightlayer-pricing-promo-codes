## Recurring or one-time: the part that decides your second bill

`2026SG20OFF` is described as a 20% recurring discount, which means the Singapore server keeps that price on every renewal. `2026SJE5DS` is presented as a monthly price, not as a coupon applied to a list price, so the discount is effectively baked in. Older codes like `LLJUNEGIFT` were flat coupons: $20 once, gone at the next invoice.

That distinction matters more than the headline percentage. A one-time 30% off a $100 server saves $30. A recurring 20% off the same server saves $240 over a year.

Lightlayer also separates new-order pricing from existing services. Price adjustments and new promotions apply to new orders; a server already running keeps the price it was bought at. So the usual fear about a cheap first year followed by a brutal renewal does not apply the way it does with consumer hosts, with one caveat: a code you apply to an existing service is not how these promotions work, so don't buy small intending to negotiate later.

## Pick the network before you pick a code

Los Angeles dedicated servers come with three bandwidth tiers, and the tier changes who the server is good for:

- **Premium Network**, 50 Mbps, test IP `38.61.2.254`. The China-optimised option.
- **Standard Network**, 200 Mbps, test IP `38.61.5.254`. More throughput, less aggressive routing.
- **Global Network**, 300 Mbps, test IP `38.61.7.254`. Cheapest per Mbps, no China priority.

Ping those three IPs from where your users actually are before ordering. A 50 Mbps Premium line that answers in 150 ms beats a 300 Mbps Global line at 300 ms for anything interactive, and the price difference between tiers is small next to the cost of picking wrong.

For the 2026 San Jose offer the routing is stated more precisely: China Telecom two-way CN2, China Mobile two-way CMIN2, China Unicom outbound direct with CMIN2 return. The Singapore servers use Telecom two-way CN2, Unicom direct both ways, and Mobile outbound CMIN2 with CN2 return.

## FAQ

**Where do I enter the code?** In the cart, at the field labelled "Promo Code", before payment. Copy the string first; the field does not validate until you submit.

**Can I stack two codes?** Nothing in Lightlayer's announcements suggests stacking. The 2024 coupon terms explicitly excluded flash-sale products from the $20 voucher, so assume one code per order.

**Why does `HKC2M` get rejected?** It was a 30-unit flash sale on 11 November 2024. The stock and the deadline are both gone.
